# 固件：给机器人接一副能被程序驱动的"手"

这里有两个 ESP32/Arduino 程序，对应两条完全不同的思路。**先看自己属于哪种，再动手。**

| | `esp32_remote_bridge` | `arduino_motor_serial` |
| --- | --- | --- |
| 干什么 | 驱动**遥控器**：红外学习回放 + 舵机压按键 | **跳过遥控器**，主机直接给电机下 PWM |
| 要不要拆机器人 | 不用（拆遥控器都不用） | 要拆，接到电机驱动板上 |
| 适用 | 任何带遥控器的成品机器人 / 玩具车 | 自己搭的小车、树莓派/STM32 底盘 |
| 通信 | Wi-Fi WebSocket（`ws://IP:81`） | USB 串口（115200） |
| 主机配置 | `DRIVER=ir` 或 `DRIVER=button` | `DRIVER=serial` |
| 难度 | 20 分钟，会插杜邦线就行 | 半天，要认电机线 |

## 一、`esp32_remote_bridge`：让程序"按遥控器"

### 1. 攒料

| 件 | 数量 | 说明 |
| --- | --- | --- |
| ESP32 开发板（DevKit / WROOM-32） | 1 | 十几块钱那种就行 |
| 红外接收头 VS1838B | 1 | 学码用，3 个脚 |
| 红外发射 LED（940nm） | 1~3 | 发码用，串 100Ω；三极管驱动更远 |
| SG90 舵机 | 0~4 | 只有压键方案才需要 |
| 杜邦线 / 面包板 / 3D 打印的舵机架 | 若干 | 架子把舵机固定在遥控器按键上方 |

### 2. 接线

```
红外接收头 VS1838B     ESP32
  OUT  ─────────────── GPIO27
  VCC  ─────────────── 3V3
  GND  ─────────────── GND

红外发射 LED  ──100Ω── GPIO26 ── (长脚正极)
              GND ────────────── (短脚)

舵机（可选，最多 4 个）
  信号线 ── GPIO13 / 12 / 14 / 15
  红色   ── 5V（一定要外部 5V，别从板上 3V3 取）
  棕色   ── GND（和 ESP32 共地）
```

> 红外发射距离短？把 LED 换成两个串联、加一只 S8050 三极管做开关，
> 或者干脆把发射 LED 贴着机器人的接收窗放。

### 3. 烧录

```bash
# Arduino IDE 里：
#   开发板：ESP32 Dev Module
#   库管理器装：IRremoteESP8266 / ArduinoJson / arduinoWebSockets / ESP32Servo
cp config.example.h config.h      # 改成自己的 Wi-Fi
```

打开 `esp32_remote_bridge.ino` 上传。串口里会看到：

```
=== jieji remote bridge ===
连接 Wi-Fi myssid....
连上了，IP = 192.168.1.42
WebSocket 端口 81，等主机连过来
```

连不上 Wi-Fi 会自动开热点 `jieji-robot` / `jieji1234`，主机连上后地址用
`ws://192.168.4.1:81`。

### 4. 在 jieji 里学按键

1. 网页右上角 **⚙ → 身体**：`driver` 选 `ir`（红外）或 `button`（舵机），
   `driver_bridge_url` 填 `ws://192.168.1.42:81`，保存。
2. **⚙ → 教它按键**：点「前进」右边的「学习」，
   - 红外：把**真遥控器**对准接收头，按下"前进"键（12 秒内）；
   - 舵机：板子会让一个舵机动一下，你看它压的是哪个键，就记住这个编号。
3. 依次学 `forward / backward / turn_left / turn_right / stop` 五个。
4. 回到主界面说一句"往前走一点"，它就会自己按遥控器了。

## 二、`arduino_motor_serial`：直接驱动电机

### 1. 接线（L298N 为例）

```
Arduino          L298N            电机
D9  (ENA/PWM) ── ENA
D8  ─────────── IN1
D7  ─────────── IN2
D10 (ENB/PWM) ── ENB
D6  ─────────── IN3
D5  ─────────── IN4
GND ─────────── GND ──────────── 电池负极（必须共地！）
                                OUT1/OUT2 → 左轮
                                OUT3/OUT4 → 右轮
                                +12V ← 电池正极

HC-SR04（可选，但强烈建议）
  TRIG ── A0
  ECHO ── A1
  VCC  ── 5V   GND ── GND
```

> **共地**是最常见的翻车点：电机电源和 Arduino 的 GND 必须接在一起，
> 否则你发什么它都不动，还会随机复位。

### 2. 烧录

库管理器装 `ArduinoJson`，打开 `arduino_motor_serial.ino` 上传。

### 3. 在 jieji 里连

**⚙ → 身体**：`driver` 选 `serial`，`driver_serial_port` 填 `COM3`（设备管理器里看），
保存。回到主界面按方向键，轮子应该转。

## 三、安全：固件里也留了一手

| 保护 | `esp32_remote_bridge` | `arduino_motor_serial` |
| --- | --- | --- |
| 命令超时 | 2 秒没命令 → 松开所有舵机 | 1 秒没命令 → 电机停 |
| 断线 | WebSocket 一断就松开全部 | 串口断开（Arduino 复位）自然停 |
| 急停 | `{"cmd":"estop"}` 立刻松开 | `{"t":"estop"}` |
| 障碍 | — | 超声波 < 15cm 且前进 → 拒绝 |

上位机（`app/safety.py`）还有限速、限时、频率限制、防撞反射、看门狗。
**两边都要有** —— 只靠上位机，一旦 Wi-Fi 掉线机器人就还在往前跑。

## 四、常见问题

**Q：红外学不到码？**
A：先确认接收头 OUT 有电平跳动（万用表或示波器）。VS1838B 的 OUT 是**低电平有效**，
接反了就是一直高。另外很多遥控器是 38kHz 载波，接收头认这个；如果你的是 2.4G 射频遥控器，
红外这条路走不通，请看 `DRIVER=button` 或直接拆机。

**Q：发码了但机器人不动？**
A：手机摄像头对着发射 LED 看一眼，应该有紫色闪烁（人眼看不见，摄像头能看见）。
有闪烁但不动 → 码不对，重新学；没闪烁 → 电路问题（LED 极性、限流电阻、GPIO）。

**Q：压键方案舵机总是抖？**
A：舵机单独供电，和 ESP32 共地；`kServoPress` 别取太极限；架子要有一定弹性。

**Q：能不能不拆遥控器、也不用舵机？**
A：能，但要看运气。私有的 2.4G 协议（nRF24 那一类）可以抓包逆向，
代价是一晚上起步、而且换一台遥控器就白干；详见 `docs/hardware.md` 的方案对比。
